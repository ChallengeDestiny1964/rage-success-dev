# Mohamed Rage Portfolio

Senior Full-Stack AI Engineer portfolio built with Next.js, React, TypeScript, and Tailwind CSS.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

- `npm run dev` — development server
- `npm run build` — production build
- `npm run start` — serve production build
- `npm run resume:pdf` — regenerate `public/Mohamed-Rage-Resume.pdf`

## Pages

- `/` Home
- `/projects` Case studies
- `/experience` Work history
- `/about` Bio + skills
- `/resume` Updated resume + PDF download
- `/contact` GitHub, email, phone, LinkedIn only
